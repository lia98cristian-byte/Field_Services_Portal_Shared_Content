HOW IT WORKS
- Add New Content: adds a video/photo/file LINK to the shared database.
- Refresh Shared Content: reloads the list immediately.
- The page also checks for updates automatically about every 30 seconds and when the browser regains focus.
- Remove: removes only the link card from the shared portal for everyone.
- The original content at SharePoint/YouTube/etc. is never deleted.

IMPORTANT SECURITY NOTE
This no-login design intentionally allows visitors who can reach the website to add and remove link cards. The Supabase anon/publishable key is safe to expose only because Row Level Security controls what it can do. If you need only managers to add/remove content, add authentication or a server-side admin layer later.
